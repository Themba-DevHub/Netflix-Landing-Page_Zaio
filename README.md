# Netflix Landing Page Clone (Themba Dev Stream)

A responsive, Netflix-inspired landing page built as part of the Full Stack AI Engineering course at Zaio Academy.

## Live Demo
- **Netlify Live Link:** [https://polite-pavlova-108678.netlify.app](https://polite-pavlova-108678.netlify.app)

## Features
- **Hero Section:** Full-viewport banner with the Netflix logo, navigation bar, headline, South African pricing, and an email signup form with floating labels.
- **Trending Now:** Five-card layout showcasing trending South African titles (One Piece, Fears & Vows, The Four of Us, How to Ruin Diwali, Blood Legacy) with poster art and hover effects.
- **More Reasons to Join:** Clean card grid highlighting key features (Smart TV streaming, offline downloads, multi-device support, and kids profiles).
- **Video Elements:** An embedded HTML5 video player with trailer controls and metadata, plus a looping video inside a Smart TV frame.
- **Plans & Pricing Table:** A South African pricing table (R59–R199/month) comparing Mobile, Basic, Standard, and Premium plans.
- **FAQ Section:** Collapsible frequently asked questions built with semantic `<details>` and `<summary>` tags without JavaScript, styled to match the Netflix dark theme.
- **Navigation & Footer:** South African support contact, full navigation link grid, language selector, and region info.
- **Responsive Design:** Basic media queries for tablet and mobile screens (Bonus).

## Technologies Used
- HTML5 (Semantic structure, forms, tables, video, details/summary)
- CSS3 (Flexbox, CSS Grid, Transitions, Media Queries)
- Google Fonts (Montserrat)

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
